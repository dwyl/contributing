## `New` Repo?

If you are setting up a `new` dwyl repo,
simply create a new file in the root of the project
called `CONTRIBUTING.md`
and copy-paste the markdown text below this line:

<hr />

```md
_**Please read** our_
[**contribution guide**](https://github.com/dwyl/contributing)
(_thank you_!)
```
